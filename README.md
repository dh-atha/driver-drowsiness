# Driver Drowsiness Detection

React + TypeScript + Vite application for driver drowsiness detection.

## Prerequisites

- Node.js `v24.14.0`
- npm `11.9.0`

## Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Optional

Build a production bundle:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
